## 司令报告审阅

周六的线上反馈、周日的自改进验收和周一的内核评审，都把重点放在如何验证 Agent 的工作，判断一致。周一头条混用了三种统计对象，会影响评测门禁的设计。[21 日](2026-11-21-commander.html) · [22 日](2026-11-22-commander.html) · [23 日](2026-11-23-commander.html)

| Google 统计项 | 能支持的判断 |
|---|---|
| 528 条 2026 年内核 CVE 记录署名致谢 Sashiko | 说明项目对已记录问题的贡献 |
| 近千个曾通过人工评审的历史缺陷，指定模型配置检出 75.8% | 衡量历史缺陷集上的检出能力 |
| 合并后 60 天返修率由历史均值 3.4% 降至 Linux 7.2 的 2.2% | 反映两个时期的差异，单凭这个比较不能确定因果 |

另一个更适合排序复核优先级的信号：同一追踪样本中，无告警补丁和带严重告警仍合并的补丁，60 天返修率分别为 0.9% 和 7.6%。[Google Cloud 工程复盘](https://cloud.google.com/blog/products/application-development/lessons-from-building-sashiko-an-agentic-code-review-system)
