## 三、关键发现

- **Top 1 与 Top 2 差距 4.1 倍**：DeepSeek 用"同门双旗舰"策略霸榜——1017 新版接棒放量（月 +924%），旧版退坡（月 -43%），内部迁移平滑完成，合计占全平台请求份额 31.8%。
- **开源 vs 闭源：开源在用量上碾压，闭源在智能指数上领跑**。周榜 Top 10 中开源/开放权重占 6 席（DeepSeek×2、GLM 5.3 Flash、MiniMax、Kimi、MiMo）；但 AA 智能指数 Top 10 全部为闭源（Claude Fable 5.2 64.6 分第一）。"开源落后闭源 3-6 个月"（OpenRouter 6 月开源 F4 报告观点，华尔街见闻转述）的判断在用量端已不成立，能力端前沿仍由闭源把持。
- **本周最大变动 = 二线国产 flash 集体爆量**：Step 5 Preview（>999%）、MiniMax M3.1 Flash（+442%）、MiMo-V2.6-Flash（+375%）三款同周冲进前十，叠加腾讯 Hy4 flash，中腰部国产模型的"价格战换量"打法见效——这四款输出价全部 ≤ $2.7/M。
- **编程（Software）占全平台花费 40.3%**，是第一大场景；编程花费 Top 5：Opus 5.5 22.3%、Kimi K3.1 Pro 10.0%、Sonnet 5.5 5.9%、GPT-6.1 Sol 5.5%、DeepSeek V4.1 Flash 1017 5.1%。高端闭源（$8-10/M 输入档）在编程上仍收溢价，但 DeepSeek 以 1/60 的价格爬到 #5。
- **Agent 应用侧**：Claude Code（1.8T tokens）、Hermes Agent（1.67T）、Kilo Code（1.15T）居 Top Apps 前三，编程 Agent 吞掉平台最大份额 token；OpenClaw 以 229B 位列 #10。

## 四、Top 5 深度分析

### 1. DeepSeek V4.1 Flash 1017 — 用量霸主的复利效应
- **核心优势**：$0.15/$0.60 的价格 + 1M 上下文 + 524 tok/s（BaseTen 最快档 #3），在"智能体推理吞吐"场景几乎无对手；月榜 222T、周 +15%，且在基础吞吐榜、上下文请求榜、编程花费榜同时在场。
- **弱项**：AA 智能指数未进 Top 10，能力天花板不及 Claude/GPT 旗舰档；1017 版对旧版存在明显的自我蚕食（V4.1 Flash 月 -43%）。
- **适用场景**：高频 Agent 循环、批量数据处理、成本敏感的生产 API。**竞品差距**：对 GLM 5.3 Flash（$0.04/$0.08）已无价格优势，靠版本迭代速度（0731→0910→1017 三连发）维持领跑。

### 2. DeepSeek V4.1 Flash — 让位的旧王
- **核心优势**：全场次低价格（$0.05/$0.20），存量用户与缓存生态仍在；周 15.3T 仍是很多"非 1017 工作流"的默认选项。
- **弱项**：月 -43%、日 -18%，退坡曲线明确；与 1017 价差仅 3 倍但能力代差存在。
- **适用场景**：已锁定的存量管线、对版本稳定性要求高于能力的场景。预计 1-2 个月内被 1017 完全替代。

### 3. GLM 5.3 Flash — 价格锚点
- **核心优势**：$0.04/$0.08 全场最低价，周 11.6T、月 +15%，是国产模型里"免费/低价档"的定价基准；GLM 系（5.3 + 5.3 Flash）合计月 73.7T。
- **弱项**：周 -2% 增长停滞；Z.ai 整体请求份额 7.0%（-3%）被 DeepSeek 压制。
- **适用场景**：超高并发、对单价极度敏感的国产化部署。竞品差距：与 DeepSeek 1017 差距从"价格领先"转为"生态落后"。

### 4. GPT-6 Luna — 闭源走量之王
- **核心优势**：$0.10/$0.50 是闭源阵营最低档，周 +34%、月 +63%，OpenAI 用它守住"轻量 Agent 默认模型"生态位；1.05M 上下文同档最大。
- **弱项**：日榜 -33%（762B），环比冲高后单日回落；智能指数未上榜，走量≠走强。
- **适用场景**：OpenAI 生态内的规模化 Agent、对合规/供应商单一化的企业。差距：价格已被国产 flash 平价甚至反超。

### 5. Claude Opus 5.5 — 花费榜的利润引擎
- **核心优势**：编程花费 22.3%（#1，-0.5pp）稳如泰山，AA 智能指数 59.1（#5），$4/$20 定价下仍有最强付费粘性；周 +49% 显示 Claude Code 生态拉动仍在。
- **弱项**：日榜 -43%（558B）冲高回落明显；在纯用量榜上（7.06T）与走量阵营差一个数量级。
- **适用场景**：复杂编程、长程 Agent 任务等"高价值低频"工作。竞品差距：Kimi K3.1 Pro 以 1/16 的输出价抢走 10% 编程花费，溢价空间正被两头挤压。
