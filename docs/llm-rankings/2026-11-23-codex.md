## 一手口径与校准

OpenRouter 按经其 API 处理的输入和输出 token 排名，页面日期指最新聚合的数据桶。上表是连续三个截至日，相邻七日窗口重叠六天。仓库快照支持第六升至第四；要证明发生条目重置，还需模型标识变更记录或平台说明。供应商份额变化也无法识别哪些用户迁移。[OpenRouter 榜单口径](https://openrouter.ai/rankings)

11 月 22、23 日表格再次把 Hy4 flash 标成闭源。官方模型卡提供权重和 Tencent Hy License。22 日摘要还称榜首模型在前五中最便宜，但同表 GLM 5.3 Flash 的输入和输出价都更低；这属于同一快照的内部矛盾，不据此判定发生调价。[腾讯模型卡与许可](https://huggingface.co/tencent/Hy4-flash) · [21 日](2026-11-21-commander.html) · [22 日](2026-11-22-commander.html) · [23 日](2026-11-23-commander.html)

## 新增海外讨论
