## 三、关键发现

### 1. Top 模型差距量化
- **断层式第一**：DeepSeek V4.1 Flash 1017（70T）= 第 2-4 名之和（28.8+15+13.2 = 57T）还多 13T。
- **头部溢价集中**：Top 4 全部是国产快思考/Flash 级模型，合计约 127T tokens，占周榜前十总量（约 158T）的 80%。
- **闭源旗舰退居次线**：GPT-6 Luna（8.14T）和 Claude Opus 5.5（6.44T）合计不足 DeepSeek 一款模型的 21%。

### 2. 开源 vs 闭源格局
- 周榜 Top 10 开源占 7 席；作者请求份额榜：DeepSeek 25.4%、OpenAI 16.8%、Google 16.1%（+24%）、腾讯 11.7%（+495%）。
- 国产开源集团军（DeepSeek + Z.ai + Moonshot + MiniMax + Qwen + 腾讯）请求份额合计约 58%，成为 OpenRouter 事实上的流量基本盘。
- 开源模型在价格上碾压：GLM 5.3 Flash（$0.12/$0.38）vs Claude Opus 5.5（$4/$20），输出价差 52 倍。

### 3. 本周最大变动
- **腾讯 Hy4 flash**：>999% 周增长 + 月榜 new，腾讯整体请求份额 +495%，是本周最大异动（注意 BYOK 封顶标注）。
- **Kimi K3.1 Pro**：编程支出份额 2.8%→9.8%（+9.7pp），今日单日 +62%，逼近 Claude 编程腹地。
- **Claude Opus 5.5**：周用量 -14%、编程份额 -1.4pp，头部闭源在性价比战场承压。

## 四、Top 5 深度分析

### 1. DeepSeek V4.1 Flash 1017（DeepSeek，开源）
- **核心优势**：70T 周 tokens 断层第一；$0.30/$1.20 定价 + BaseTen 541 tok/s 高吞吐；月度 +576% 说明生态迁移仍在加速。10/17 快照成为默认生产选择。
- **弱项**：闭源旗舰级复杂推理仍有差距；旧快照 V4.1 Flash（-6%）正在被 1017 快照替代，存在版本碎片。
- **适用场景**：高并发生产 API、成本敏感的 Agent 批量任务、代码补全。
- **竞品对比**：对 GLM 5.3 Flash 保持 5 倍用量优势；唯一能威胁它的是腾讯 Hy4 flash 的价格战。

### 2. Hy4 flash（腾讯，闭源，BYOK 标注 *）
- **核心优势**：$0.035/$0.14 是本周 Top 10 最低价（输出价约为 DeepSeek 1017 的 1/8）；周环比 >999%、月榜 new，定价屠夫策略见效。
- **弱项**：BYOK 封顶标注意味着部分企业自有 key 流量被折算，真实增速可能被低估但也提示流量结构单一；benchmark 数据缺失，能力上限未知。
- **适用场景**：海量低成本推理、国内出海业务、价格敏感型应用。
- **竞品对比**：以 1/8 的 DeepSeek 价格拿到 41% 的 DeepSeek 用量，若能力达线将持续抢份额。

### 3. DeepSeek V4.1 Flash（旧快照）
- **核心优势**：$0.14/$0.42 更低价，大量存量生产管道仍在使用，15T tokens 基本盘稳固。
- **弱项**：周 -6%、月 -45%，流量明确向 1017 快照迁移；将被逐步淘汰。
- **适用场景**：未升级快照的存量客户；新项目应直接选 1017。
- **竞品对比**：内部新旧快照交替是本周 DeepSeek 阵营唯一负增长点。

### 4. GLM 5.3 Flash（Z.ai，开源）
- **核心优势**：13.2T（+14%）稳居第 4；$0.12/$0.38；原生多模态 + 混合稀疏/线性注意力，适合长程 Agent 任务；衍生出 FlashX（200 tok/s）、Legal 垂直版等产品矩阵。
- **弱项**：增速（+14%）落后于 MiniMax（+36%）和 Kimi（+29%），第二梯队内部竞争加剧。
- **适用场景**：多模态 Agent、编程辅助、中文场景长上下文。
- **竞品对比**：与 DeepSeek 合计构成国产开源双雄，但单点增速已被反超。

### 5. GPT-6 Luna（OpenAI，闭源）
- **核心优势**：闭源阵营用量第一（8.14T）；$0.10/$0.50 是 OpenAI 史上最激进的轻量定价；1.05M 上下文。
- **弱项**：周 -3%、月榜第 4（35.4T）与开源阵营差距明显；单日 -9%，缺乏增长动能。
- **适用场景**：日常对话、客服、对生态/合规有要求的海外业务。
- **竞品对比**：以价格换量但增速仍不敌国产 Flash 军团；OpenAI 增长亮点转向 GPT-6.1 Sol（+93%）和 GPT-6.2 新系列（batch 快速放量）。
