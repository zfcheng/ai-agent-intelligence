## Key Updates

- Flowise reaches its official end-of-life date today, after the July 29 code freeze and August repository archival. This is a useful market signal, not just a project sunset: visual low-code agent builders are struggling where production teams now need code-native review, versioning, MCP/tool contracts, evals, and deployable harnesses. Sources: [Flowise sunset](https://flowiseai.com/sunset), [GitHub discussion #6727](https://github.com/FlowiseAI/Flowise/discussions/6727), [GitHub repository](https://github.com/FlowiseAI/Flowise)
- LangChain/LangSmith remained the strongest target-account production signal going into the US day: the August update packages Managed Deep Agents public beta, LLM Gateway, Engine's claimed >2x issue-detection lift and 25% stronger fixes, Tuned Evaluators, BYOC on AWS, and PR-scoped Preview Builds into one agent operating layer. The synthesis is that "agent framework" is becoming "agent control plane": deployment, traces, online quality signals, cost/rate/fallback policy, sandboxing, and private-cloud data planes are now bundled requirements. Sources: [LangChain August newsletter](https://www.langchain.com/blog/august-2026-langchain-newsletter), [LangSmith Engine](https://www.langchain.com/blog/new-in-langsmith-engine-2x-better-issue-detection/), [Tuned Evaluators](https://www.langchain.com/blog/introducing-langsmith-tuned-evaluators-starting-with-perceived-error/), [BYOC on AWS](https://www.langchain.com/blog/langsmith-byoc-is-now-generally-available-on-aws/), [Preview Builds](https://www.langchain.com/blog/langsmith-preview-builds-test-agent-changes-before-production)
- The late-August benchmark queue converged on the same point from different angles: Same Model, Different Harness shows solver results can change when only the harness changes; FaulT-Bench adds false-premise and healthy-network tickets to network troubleshooting; SPA uses plan-first information-flow control for persistent agents; and the MCP hardware-design benchmark tests local open-weight agents under proprietary-tool and confidentiality constraints. Treat these as harness and governance evidence, not model leaderboard evidence. Sources: [Same Model, Different Harness](https://arxiv.org/abs/2608.26218), [FaulT-Bench](https://arxiv.org/abs/2608.27021), [SPA](https://arxiv.org/abs/2608.27234), [MCP hardware-design benchmark](https://arxiv.org/abs/2608.26199)

## Hot Discussions

- Agentic-infra security discussion stayed hot after @rauchg amplified the new JFrog Artifactory CVE during US daytime. The official JFrog advisory confirms a critical authentication weakness that can lead to administrative access in affected self-hosted Artifactory versions, but social claims about agent discovery or exploitation should be kept separate from the official advisory until independently sourced; the operational action is immediate self-hosted upgrade plus agent-sandbox egress and artifact-store monitoring. Sources: [@rauchg post](https://x.com/rauchg/status/2094122005193003077), [JFrog advisory](https://docs.jfrog.com/releases/docs/jfrog-security-advisories), [IONIX summary](https://www.ionix.io/threat-center/cve-2026-82329/)
- The practical MCP/coding-agent control thread sharpened around effects, not labels. Thomas De Vos' Aug 29-30 examples show two failure classes worth adding to eval suites: a "read-only" MCP method can still trigger billable queries, exports, webhooks, and audit-state changes, and a paginated tool response can make an agent declare whole-collection success after only the first page. Sources: [read-only MCP effects](https://thomasdevos.com/posts/2026-08-30.10.43.30-claude-code-called-a-read-only-mcp-tool-186-times-the-bill-said-otherwise/), [pagination completeness](https://thomasdevos.com/posts/2026-08-29.10.44.29-claude-code-checked-the-first-page-and-called-the-job-done/)

## Actionable Insight

- For private-cloud or enterprise agent work, define the release artifact around the run, not around the chat transcript: model and harness version, loaded skills, tool effect contracts, credential scope, preflight cost estimate, shared parent/subagent budget, source snapshot, pagination/completeness receipt, online evaluator output, human approval, and post-run provider receipts. The next useful eval additions are false-premise/no-fault tickets, undeclared side effects, incomplete pagination, stale memory claims, and evidence-reversed action-boundary cases.
