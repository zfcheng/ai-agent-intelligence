## Key Updates

- LangChain/LangSmith's recent trajectory-analysis push is the most relevant production signal: the center of gravity is moving from "did the final answer pass?" to inspecting intermediate tool choices, retries, branches, and failure recovery as first-class evaluation artifacts ([LangChain blog](https://www.langchain.com/blog), [LangSmith docs](https://docs.smith.langchain.com/)).
- Managed deep-agent patterns are also becoming more productized: durable state, long-running execution, tool-call supervision, and traceable sub-agent behavior are increasingly treated as platform responsibilities rather than application glue code ([LangGraph docs](https://langchain-ai.github.io/langgraph/), [LangChain blog](https://www.langchain.com/blog)).
- OpenAI's Agents SDK remains an important parallel reference point for harness design because tracing is built into the agent loop abstraction itself, making tool spans, handoffs, and guardrail failures easier to connect to evals and regression suites ([OpenAI Agents SDK docs](https://openai.github.io/openai-agents-python/)).

## Hot Discussions

- The previous US daytime discussion stayed focused on containment after recent unintended-agent-action reports: teams are treating browser/network access, external writes, credentials, and final-submit actions as explicit test dimensions instead of assuming the eval harness is isolated by default ([Anthropic research](https://www.anthropic.com/research/investigating-unintended-model-actions)).
- Agent observability is converging with mainstream APM: OpenTelemetry-style traces, session-level views, tool-call cost attribution, and eval-linked failure review are becoming the common language between AI platform teams and SRE/DevOps teams ([OpenTelemetry AI semantic conventions](https://opentelemetry.io/docs/specs/semconv/gen-ai/), [LangSmith docs](https://docs.smith.langchain.com/)).
- The FDE/PDE operating model remains a bottleneck theme for enterprise agents: the practical work is less "install an agent framework" and more embedding engineers close enough to customer workflows to define safe tools, action boundaries, approval gates, and measurable success criteria.

## Actionable Insight

- For private-cloud agent pilots, standardize every eval record as `model x graph/harness x tools x network boundary x credentials x approval gates x budget x judge x trajectory`. Add trajectory review before any self-improvement loop so the system optimizes recoverable behavior and containment, not only final-answer pass rate.
