## Key Updates

- **Sashiko 把误报纳入性能评审验收。** 11 月 21 日 03:18（上海）发布的 0.9.5 可为 Linux 补丁启用性能专项检查。项目自测中，20 个历史性能回归命中数从 3 升至 14；20 个对照提交中有 12 个完全无告警。每个提交的输入 token 中位数增加 11%。这些数值能说明同一小样本的增益和代价，生产门禁仍需本业务对照组。[Sashiko 0.9.5](https://github.com/sashiko-dev/sashiko/releases/tag/v.0.9.5) · [项目评测表](https://github.com/sashiko-dev/sashiko/pull/917)
- **Claude Code 为自托管 runner 增加两个启动指标。** 上海时间 11 月 21 日 06:32 提交的 2.1.330 更新记录，分别测量从派发工单到注册获准、到交付首个会话的耗时。若注册耗时稳定而首会话变慢，可优先检查注册后的会话交接；比较时需按 runner 类型和适用会话分组。同一记录还列出并发会话误删其他会话使用中的 worktree 的修复，可作为升级回归用例。[Claude Code 更新记录](https://github.com/anthropics/claude-code/commit/e791a1c41eee7504672a109fd6eb66b11566b8a1)

## Hot Discussions

11 月 22 日，Stitch Skills 贡献者记录必需文件缺失时检查脚本仍返回 0，附上正反输入及退出码。用这类样本测工具结果解析，比只核对 Agent 最终回复更容易发现错误放行。腾讯团队在 Reddit 的 AMA 则提供了活跃参数、硬件与质量取舍的解释，详见排名校准。[Stitch Skills PR #111](https://github.com/google-labs-code/stitch-skills/pull/111) · [腾讯团队 Reddit AMA](https://www.reddit.com/r/LocalLLaMA/comments/1y15w4a/tencent_hy_team_shunyu_yao_here_ask_us_anything/)
