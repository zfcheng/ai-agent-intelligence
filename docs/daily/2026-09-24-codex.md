## Key Updates
- LangChain's strongest carry-over signal from the US day was the move from generic LLM-as-judge to cheaper typed judgment inside the harness: the recent Jev series covers building a harness with Jev, using Jev-as-a-Judge for agent evals, and making Jev available in LangSmith Evals. Read this as a production pattern, not a model story: agents need fast, structured, low-cost graders that can run inside traces, CI, and regression loops. Sources: [LangChain blog](https://www.langchain.com/blog), [LangSmith release index](https://releases.sh/langchain/langsmith).
- Dash0 updated Agent0 documentation on Sept. 23, positioning AI SRE as a continuous loop that scans telemetry, finds degrading services without alert coverage, traces issues to commits, and drafts pull requests. The important bit is the operating surface: sandboxed command execution, OpenTelemetry-native reads, GitHub/GitLab, Linear, MCP, SQL, Bash, Slack, and automations. Sources: [Dash0 Agent0 overview](https://www.dash0.com/docs/dash0/ai/agent0/overview), [Dash0 Agent0 product page](https://www.dash0.com/ai-sre-agent/).
- OpenAI's current developer surface reinforces the same harness direction: Agents API public beta provides managed Codex-harness sessions, compaction, recovery, sandboxes, progress streaming, and MCP/tool connections, while the Sept. 23 developer blog showcased Codex plus GPT-Live controlling a physical LED assistant. The production takeaway is that voice, code, device state, and long-running agent sessions are becoming one deployable runtime rather than separate demos. Sources: [OpenAI API changelog](https://developers.openai.com/api/docs/changelog), [OpenAI Developers blog](https://developers.openai.com/blog).

## Hot Discussions
- The OpenClaw/Muse debate kept turning "agent personality files and workspace conventions" into a mainstream harness-design topic. Meta's Nat Friedman said Muse was built from scratch but heavily inspired by OpenClaw; the useful discussion is not cloning drama, but which artifacts become durable product primitives: `SOUL.md`, persistent instructions, tool/workspace boundaries, restart recovery, plugin discovery, and cloud-session snapshotting. Sources: [TechCrunch](https://techcrunch.com/2026/09/22/meta-admits-muses-likeness-to-openclaw-isnt-a-coincidence/), [OpenClaw news tracker](https://www.theclawreport.com/).
- Security guidance is converging on "govern the harness, not just the model." Australia's ASD framed the harness as the layer where long-term organizational value, risk, permissions, memory, audit, and controls accumulate; it also notes that prompt injection cannot be reliably solved in the model alone. Pair that with recent indirect-prompt-injection research treating attacks as test-time search, and the implication is clear: eval budgets, attacker search strategy, tool privileges, and trace evidence must be part of security testing. Sources: [ASD Agentic AI harnesses](https://www.cyber.gov.au/business-government/secure-design/artificial-intelligence/agentic-ai-harnesses), [arXiv 2609.04495](https://arxiv.org/abs/2609.04495).

## Actionable Insight
- For the next internal agent pilot, build a small "harness contract" before adding more autonomy: typed evals for key decisions, trace replay, per-tool least privilege, sandbox provenance, cost budgets, human approvals for high-impact actions, and an incident-ready log of prompts, tool calls, outputs, approvals, and rollback state. Treat the FDE/SRE review as part of the runtime: if an embedded engineer cannot inspect, reproduce, and reverse an agent action, the agent is not production-ready.
