## Key Updates

- **记忆评测应加入“相似但不适用”的反例。** 11 月 26 日 01:30（上海）提交的 TASK Memory 在预注册实验中将 CounterFact 相邻问题误用记忆的比例从 39.2% 降至 7.5%。这个分母与“正确记住了多少条”不同。对企业知识助手，可把更新后的有效事实、相似实体和已失效事实放在同一组回归用例中。[TASK Memory 论文与提交记录](https://arxiv.org/abs/2611.34762)
- **去重加速能否缩短整次调研，有了同输入对照。** 11 月 27 日 05:14（上海），last30days-skill 合入 Rust 加速组件。1,000 条去重微基准快 46.9 倍，一次联网任务从约 31 秒缩至 19 秒；作者还对照了返回条目和聚类。上线门禁可同时检查结果一致性、端到端耗时和 Python 回退。[项目 PR 与 A/B 表](https://github.com/mvanhorn/last30days-skill/pull/1635)
