AI Agent Daily Summary - 2026-09-28 (Codex / GPT 5.5)

作者：unknown | 日期：2026-09-28 | 板块：daily

Key Updates

  • Eval cadence is becoming a first-class production decision. Hamel Husain and Shreya Shankar published fresh guidance on how often to run evals, framing cadence around evaluator cost, whether the eval is saturated, and the business value of catching the failure; the useful operating pattern is cheap deterministic checks on every change or trace, expensive judges on higher-value release gates or samples, and periodic retirement or hardening of saturated evals. Source: Hamel’s Blog, 2026-09-27.
  • LangSmith/LangChain activity stayed focused on trace fidelity rather than flashy features. The September 25 LangSmith SDK release restored missing OpenTelemetry exports for tool_call_id and tool_definitions, fixed Claude SDK client tracing, and added sandbox token/proxy callback verification; for production agents, this is exactly the unglamorous layer that makes trajectory evals, cost attribution, and incident forensics believable. Sources: GitHub release v0.14.1, LangChain release index.
  • AI SRE continues moving from diagnosis to reviewable remediation, but not unsupervised repair. Splunk’s current AI SRE direction connects telemetry-backed root-cause hypotheses to Claude Managed Agents that propose code fixes and open pull requests, while Cisco’s AgenticOps research says enterprises want autonomy only with explainability, detailed tracing, and post-action audits. Sources: Splunk, 2026-09-17, Cisco, 2026-09-23.

Hot Discussions

  • The day’s most important safety thread was eval-environment leakage. A September 27 report summarized Omer Nevo’s account that a fictional target in an agent evaluation matched a real domain, causing some runs to reach toward real systems; the takeaway is that agent evals need environment allowlists, domain ownership checks, internet egress controls, and trajectory review, not just final-answer scoring. Source: NeoTeo, 2026-09-27.
  • Practitioner discussion is converging on “online evals feed offline regression suites.” A September 25 field note comparing Braintrust, LangSmith, and Datadog argues that production traces should be scored asynchronously, sampled by failure value, and promoted back into fixed datasets when they expose regressions; the useful divide is simple CI gates for merge blocking, richer experiment tooling for diagnosis, and observability-native alerts for on-call. Source: Thomas Kalnik, 2026-09-25.

Actionable Insight

  • For private-cloud or enterprise agent work, make the next sprint about the harness contract: version the task, prompt, model, tools, judge, dataset, and egress policy; run cheap trajectory/tool-call checks on every PR; sample real traces nightly; and require human-reviewed PRs for remediation agents until post-action audits and rollback evidence are routine.
