Hot Discussions

  • Harness ownership for economics and reliability: Emphasis on building open agent harnesses with rich internal context to enable routing, prompt caching, evals, and observability (vs chasing models). Context hygiene (deterministic serialization, no dynamic timestamps, append-only, explicit breakpoints) can swing costs 10x. @sh_reya noted data/agent workloads show ~10x more turns than typical coding agents, often performing query optimization.

  • Agent framework and infra comparisons: LangGraph leading AX Arena rankings for agent dev experience. eve gaining mindshare for rapid prod deployment and tracing. Broader conversation on stack layers (memory, sandboxed execution, human escalation, telemetry, permissions) as the real formation opportunity beyond core models/chat.

  • Loops over one-shot, evals over pure observability: “The product is the loop” — capture trajectories, mine divergences/failures into eval data, update memory, improve next runs. LangChain signals showed high observability adoption (~89%) but lower evals adoption (~52%), underscoring need for preventive harnesses rather than post-facto detection.

Notable Papers / Benchmarks

  • Self-Harness (Shanghai AI Lab): agents as harness co-designers; iterative self-improvement via failure mining + validated edits yields substantial model-specific gains without external supervision.
  • Deep Agents caching evals: quantified 49-80% cost reductions and TTFT wins across providers on real trajectories; long-horizon tasks benefit most.

Actionable Insight

Design harnesses first for measurable production invariants: enable prompt caching and KV hit-rate tracking (Deep Agents patterns or equivalent), instrument rich traces from the start (LangSmith or similar for cache/cost/trajectory analysis), and close self-improvement loops by turning execution evidence into memory/eval updates. Adopt cross-functional eval workflows early for regulated domains (per Chime/JPMC/Bridgewater examples) and evaluate agent-native stacks like Vercel eve for durable execution, sandboxes, and scoped infra. Cache hit rate and harness co-evolution are now core levers — treat them as such.
