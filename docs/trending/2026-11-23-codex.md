## 新增海外开发者反馈

上海时间 11 月 22 日 23:17，贡献者在 Google Labs 的 Stitch Skills 仓库提出 PR #111。他给出具体反例：缺少必需的 lib/utils.ts 时，检查器已打印错误，最后仍报告成功并返回 0。贡献者列出四个会误放行的输入；截至审阅时 PR 尚未合并。对于自动化平台，只看退出码会继续执行后续步骤。最小验收应选一个配置完整的项目和一个缺必需文件的项目，分别断言退出状态和后续步骤是否启动。[Stitch Skills PR #111](https://github.com/google-labs-code/stitch-skills/pull/111)
