## 司令报告审阅

周四至周五，CLI-Anything 在两份快照中的日增星由 389 到 898。判断一致：值得跟踪 Agent 可调用的软件接口。仅凭两天星数还无法判断有多少团队在 CI 中持续使用。[11-19 司令](2026-11-19-commander.html) · [11-20 司令](2026-11-20-commander.html)

## 一手核查与新增条目

周五上榜的 OpenSRE 提供了比星数更可检验的功能：读取 GitHub Actions 失败运行后，调查可归入 CI 原因、代码原因或原因未明。试用时给它各一例，并保留没有足够日志的一例，检查系统是否如实留下未决状态。该工作流是本次对榜单的补充核查。[OpenSRE 工作流](https://www.opensre.com/how-it-works)

周四表中 Heretic 的两处分类不一致。按项目作者说明，它是修改语言模型行为的工具，Python 是实现语言。已在原文末尾补充更正。[作者项目说明](https://github.com/p-e-w/heretic)
