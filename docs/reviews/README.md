# 🔍 每周 Review（Codex 云沙箱负责）

> Codex 每周审阅司令当周的全部产出（ai-loop / llm-rankings / trending / pricing），
> 从全球视野补盲区、纠偏、给独立判断。

## Review 输出规范

- 文件名：`YYYY-Www.md`（如 `2026-W47.md`）
- 结构：
  1. **本周遗漏** — 全球范围内有但司令没覆盖到的信号
  2. **纠偏** — 对司令判断的不同意见及依据
  3. **补充视角** — 海外社区/论文/一手信息中值得注意的
  4. **下周关注** — 建议盯的方向
- frontmatter：`type: reviews`、`author: codex-sandbox`

## 数据来源

司令的产出都在 `docs/ai-loop/`、`docs/llm-rankings/`、`docs/trending/`、`docs/pricing/`，按日期取当周文件即可。
