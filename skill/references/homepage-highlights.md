# 首页热点摘要生成规则

> 路径：`docs/index.md` 的 `<div class="cards">` 区域
> 触发时机：每次 cron 提交新报告后，同 commit 或紧随其后更新首页热点
> 谁负责：司令（index.md 归司令维护）

## 规则

### 1. 结构

每个板块卡片包含：
- `card-header`：图标 + 标题 + 主责人
- `card-desc`：一句话描述
- `card-highlights`：**5 条近期热点摘要**（见下方规则）
- `card-footer`：查看链接 + 报告计数（Liquid 自动）

### 2. 热点摘要内容规则

每个板块的 5 条热点从该板块**最近 3 天的报告**中提取，按优先级：

1. **用户工作画像直接相关**（`docs/work-profile.md` 中的方向）→ 最高优先级，必须包含
2. **技术风向标**（框架/工具/生态重大变化）→ 高优先级
3. **数据异动**（用量/排名/价格突变 >50%）→ 中优先级
4. **新模型/新产品发布** → 中优先级
5. **行业趋势判断**（洞察段的核心结论）→ 低优先级

### 3. 格式规范

每条热点格式：
```html
<li><strong>MM-DD</strong>：简洁陈述（核心信息 + 一句话价值点）</li>
```

要求：
- **日期**：取报告日期或事件日期，两位月 + 两位日
- **陈述**：15-50 字，包含关键实体和核心变化
- **不含链接**：首页热点不嵌超链接，点击卡片进入板块页查看详情
- **不含来源**：不标注来源 URL，保持卡片干净
- **中文为主**：术语保留英文原名

### 4. 更新频率

- 司令 cron 每次提交新报告后，**同步更新**对应板块的热点（同 commit 或紧随其后）
- Codex 提交 daily 报告后，司令在下次更新时同步补充 Daily 板块热点
- 如有 3 天无任何新报告，热点区顶部追加一条「近期无重大更新」并简要说明原因

### 5. 板块热点示例

**AI Loop 日报**：从报告的「头条」和「今日洞察」提取，聚焦 Coding Agent Loop / Agentic 框架 / 自修复 / HITL

**LLM Rankings**：从报告的「异动监控」和「深度分析」提取，聚焦用量突变 / 新模型 / 排名变化

**GitHub Trending**：从「分析与判断」和 Top 10 表提取，聚焦 AI 相关项目 / 技术风向 / 与工作画像相关

**Daily Summaries**：从 Codex 日报的「头条」提取，聚焦全球 AI Agent 情报

**Pricing Alerts**：从报告的异动条目提取，聚焦价格突变 / 免费策略 / 性价比变化

**Blog Monitor**：从报告的厂商公告提取，聚焦产品发布 / 价格调整 / 重大更新

**Insights**：从周报的 ACT 建议提取，聚焦可行动项 / 工作匹配

### 6. 质量红线

- 热点摘要不是报告摘要的缩写——而是**过滤后的精华**，每条都必须有信息增量
- 禁止重复：同一条信息不要出现在多个板块的热点中
- 禁止空泛：「值得关注」不是热点，必须有具体实体和变化
- 司令和 Codex 均遵守此规则

## Liquid 动态部分（不可手动编辑）

以下区域由 Liquid 自动生成，**不要手动修改**：
- `card-footer` 中的 `card-count`（报告计数）
- 底部「最近更新」区域的各板块列表

## 与 AGENTS.md 的关联

本规则是 AGENTS.md 第 5 条「index 更新」的细化补充。司令负责执行，Codex 监督。
